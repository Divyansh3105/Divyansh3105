### 👋 About me

I learn by building, not by following tutorials. When I care about something (a game, an anime, the solar system) I end up building something around it, and that's how I picked up most of what I know. I started with front-end and UI; these days most of my projects have a real backend behind them: auth, databases, real-time features and LLM APIs.

### ⭐ Featured: Playdex

**All your Steam, Epic and GOG games in one desktop app, with a finder for games you own twice.**

<p>
  <a href="https://apps.microsoft.com/detail/9PMW08P8FQK8"><img src="https://get.microsoft.com/images/en-us%20dark.svg" height="40" alt="Get it from Microsoft" /></a>
  &nbsp;
  <a href="https://github.com/Divyansh3105/playdex/releases/latest"><img src="https://img.shields.io/github/v/release/Divyansh3105/playdex?style=flat-square&color=00F79E" alt="Latest release" /></a>
  <a href="https://github.com/Divyansh3105/playdex/actions/workflows/tests.yml"><img src="https://img.shields.io/github/actions/workflow/status/Divyansh3105/playdex/tests.yml?style=flat-square&label=tests" alt="Tests" /></a>
</p>

<a href="https://github.com/Divyansh3105/playdex"><img src="https://raw.githubusercontent.com/Divyansh3105/playdex/main/docs/demo.gif" width="85%" alt="Playdex demo: library, filters, stats and disk space" /></a>

My games were spread across three launchers and I kept forgetting which one had which. Playdex reads each launcher's local data and merges everything into one library: duplicate-ownership finder, playtime tracking, disk usage, and a backlog picker. No logins, nothing uploaded.

`Electron` `Node.js` `SQLite` · [Source](https://github.com/Divyansh3105/playdex) · [Microsoft Store](https://apps.microsoft.com/detail/9PMW08P8FQK8)

### 🔨 Currently building

- 🚨 **[RescueAI](https://github.com/Divyansh3105/RescueAI): explainable decision support for disaster rescue in Uttarakhand** (my B.Tech major project). Ranks rescue requests, matches volunteers and SDRF/NDRF teams, and shows how every score was calculated. A human approves every dispatch and every decision is audit-logged.
- 📊 **[RepoScope](https://github.com/Divyansh3105/RepoScope): turns GitHub profiles and CSV files into stats and charts** using plain PHP and hand-drawn HTML5 Canvas. No frameworks, no chart libraries, no database.
